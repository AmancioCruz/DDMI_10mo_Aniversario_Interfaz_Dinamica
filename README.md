## Tipografías de referencia

- Nohemi: https://befonts.com/nohemi-font-family.html
- Denton: https://peregrinstudio.com/work/denton

## Uso tipográfico previsto

- Nohemi: cuerpo de texto y textos informativos.
- Denton Variable: tipografía secundaria.
- PPMondwest-Regular: tipografía principal de apoyo con estilo bitmap.
- PPNeueBit-Bold: títulos, marca, menú y elementos de interfaz.
